# TRExFitter Template Param Fit

This task trains agents to run TRExFitter's 1D template-parametrization
example. The verifier checks the `h/t/w/f` sequence, including creation and use
of `Templates/Parametrization.txt`.

Run the oracle locally with:

```bash
harbor run -p tasks/trexfitter-template-param-fit -a oracle
```
